# Домашняя аптечка (apteka-tracker)

[![CI](https://github.com/Nikit-04ka/apteka-tracker/actions/workflows/ci.yml/badge.svg)](https://github.com/Nikit-04ka/apteka-tracker/actions/workflows/ci.yml)

Небольшая Windows-программа на Rust для учёта лекарств домашней аптечки и их
сроков годности. Одиночный портативный `.exe`, данные хранятся рядом с программой.

![Скриншот интерфейса](docs/screenshot.png)

## Скачать

Готовый `apteka-tracker-<версия>-windows-x64.exe` лежит на странице
[Releases](../../releases): скачайте, положите в любую папку и запускайте —
установка не требуется. Релиз собирается автоматически пушем тега `vX.Y.Z`
(см. `.github/workflows/release.yml`).

## Возможности

- **Лекарства**: название, форма (таблетки, мазь, сироп, …), заметки
  и **категории** — свободные теги («жаропонижающее», «детское», …) с
  фильтром по категории в шапке и поиском по ним.
- **Несколько упаковок у одного лекарства** — каждая со своим сроком годности,
  количеством, ценой, датой покупки и комментарием.
- **Жизненный цикл упаковки**: запечатана → кнопка «Открыть» (с периодом после
  вскрытия в днях — эффективная дата годности пересчитывается) → «Израсходовано»
  или «Выбросить» (списание: карточка гаснет, из активного учёта уходит, но
  остаётся в базе — видно по кнопке «Показать списанные», можно «Вернуть»).
  Опасные действия — «Открыть» и «Удалить» (у списанной — «Удалить навсегда») —
  подтверждаются вторым нажатием: кнопка меняется на «Точно …?», `Esc`
  отменяет. После удаления подсказка в статусной строке напоминает про Ctrl+Z.
- **Цены**: сводка «Стоимость» считает только активные упаковки.
- **Календарь** у поля срока годности: выбор даты мышью, «сегодня» подсвечен.
- **Список покупок**: кнопка «Что купить» собирает просроченные и истекающие
  упаковки в отдельное окно, «Скопировать» кладёт список в буфер обмена.
- **Отчёты**: кнопка «Отчёты» — списания и покупки по годам (для покупок
  заполните поле «Куплена» у упаковки), самая старая активная упаковка.
- **Фото упаковок**: снимок прикрепляется к карточке; для экономии памяти и
  места хранится уменьшенная копия — миниатюра до 480 px (поворот по EXIF
  учитывается). Если файл фото потерялся, карточка показывает плейсхолдер —
  клик по нему открывает выбор нового файла; потерянные файлы чистятся
  при запуске.
- **Автодополнение названия** по уже заведённым лекарствам.
- **Импорт CSV**: кнопка «Импорт CSV» читает файлы экспорта рядом с программой
  и добавляет данные к существующим. Повторный импорт того же файла не создаёт
  дубликатов — записи сверяются по названию и форме.
- **Подсветка статусов** (от сегодняшней даты):
  - 🔴 красный — срок истёк;
  - 🟡 жёлтый — срок истекает в пределах порога (по умолчанию 60 дней, настраивается);
  - 🟢 зелёный — всё хорошо; серый — упаковок ещё нет.
- Лекарство в списке показывает **худший** статус своих упаковок и ближайший срок.
- Поиск по названию/форме/заметкам/категориям, фильтры «Все / Истекают /
  Просроченные» плюс фильтр по категории, сортировка по ближайшему сроку
  или по названию.
- Сводка сверху: всего лекарств, упаковок, сколько истекает и просрочено.
- Живая валидация даты в форме упаковки: сразу показывает, каким будет статус.
- Быстрый выбор срока: «+6 мес.», «+1 год», «+2 года». Кнопка «Клонировать» у
  упаковки копирует её количество/комментарий в форму новой упаковки
  (срок по умолчанию — сегодня + 1 год), удобно при покупке такой же пачки.
- Тёмная/светлая тема (кнопка «Тема», выбор запоминается), экспорт CSV
  (открывается в Excel).
- **Журнал событий**: кнопка «Журнал» открывает окно с хронологией
  (добавления/изменения/открытия/списания; хранятся последние 400 событий).
- Автосохранение после каждого изменения.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `↑` / `↓` | перемещение по списку лекарств |
| `Ctrl+N` | новое лекарство |
| `Ctrl+F` | перейти к поиску |
| `Ctrl+Z` | отменить последнее действие |
| `Ctrl+Y` (или `Ctrl+Shift+Z`) | вернуть отменённое |
| `Delete` | удалить выбранное лекарство (в два шага: «Точно удалить?») |
| `Esc` | отмена: сброс подтверждений удаления, редактирования упаковки, подсказок автодополнения |
| `Enter` (в поле названия) | принять первую подсказку автодополнения |

Кнопки «Отменить» / «Вернуть» — в статусной строке внизу окна.

## Надёжность

- **Автобэкап**: раз в сутки при первом запуске и при первой мутации нового
  дня копия данных кладётся в `backups/` (рядом с exe), хранятся последние
  5 копий. Если файл данных правили вручную уже после копии — при следующем
  запуске будет сделана свежая копия (защита ручных правок). Перед
  восстановлением из бэкапа текущее состояние всегда сохраняется отдельной
  копией, а сама операция отменяется через Ctrl+Z.
- **Один экземпляр**: повторный запуск показывает сообщение «уже запущена» —
  два окна над одним файлом данных невозможны (файловый замок `apteka.lock`
  освобождается автоматически, в том числе после сбоя).
- **Аварийный лог**: при внутренней ошибке (панике) подробности пишутся в
  `apteka_crash.log` рядом с программой и показывается сообщение — сбой можно
  сообщить и починить.
- **Пересчёт статусов**: раз в час подсветка обновляется по текущей дате,
  даже если приложение открыто через полночь.
- **Отмена/повтор**: до 50 шагов истории на сессию; правки одного поля
  у одного лекарства (например, набор названия по буквам) склеиваются
  в один шаг.
- **Нечитаемый файл данных** (занят другой программой, права доступа):
  программа сообщит об ошибке и закроется, НЕ перезаписывая ваши данные.
- **Повреждённый JSON**: сохраняется как `*.corrupt-<дата>` (не удаляется),
  программа стартует с пустой базой и сообщает об этом в статусной строке.
- **Все ошибки** (сохранение, импорт, фото, бэкап) показываются красной строкой
  в статусной строке — полностью, с переносом, и держатся до следующей
  успешной операции, чтобы их успеть прочитать; часть ошибок выводится
  отдельным сообщением. Ни одна не проглатывается молча.
- Подтверждения опасных действий (удаление лекарства/упаковки, вскрытие
  упаковки) сопровождаются подсказками, а после выполнения — фактом и путём
  отката («вернуть: Ctrl+Z»).

## Сборка

Нужен Rust 1.92 или новее (https://rustup.rs; минимальная версия зафиксирована
в `Cargo.toml`). Затем:

```powershell
cargo build --release
```

Готовый файл: `target\release\apteka-tracker.exe`. Его можно скопировать в любую
папку и запускать — установка не требуется.

## Данные

- Файл данных: `apteka_data.json` — создаётся **рядом с exe** (портативный режим).
  Внутри есть поле `version` — при изменении схемы старые файлы читаются
  и мигрируются автоматически.
- Настройки окна (размер, положение, тема): `settings.json` рядом с exe.
- Фото упаковок: `photos/` рядом с exe (потерянные файлы чистятся при запуске).
- Экспорт: `apteka_export.csv` — тоже рядом с exe (кнопка «Экспорт CSV»);
  колонки: лекарство, форма, заметки, срок, дней до конца, статус, количество,
  цена, открыта, списано, комментарий, категории, куплена, период после
  вскрытия.
  Импорт возвращает и жизненный цикл упаковки (вскрытие, период после
  вскрытия, списание) — экспорт/импорт без потерь.
- Повреждённый файл данных не удаляется: сохраняется как
  `apteka_data.json.corrupt-<дата>` и программа стартует с пустой базой.

## Сроки годности «до месяца»

Производители часто указывают срок без дня: «Годен до 01 2028». Аптечная конвенция —
препарат годен **до конца** указанного месяца. В программе достаточно ввести
`01.2028` (или `2028-01`, `01/2028`, `01 2028`) — статус рассчитается до 31.01.2028
включительно, а в списке срок отобразится как `01.2028`. Полные даты
(`ГГГГ-ММ-ДД`, `ДД.ММ.ГГГГ`) считаются как обычно.

## Формат даты

В полях срока годности принимаются: `ГГГГ-ММ-ДД`, `ДД.ММ.ГГГГ` и `ММ.ГГГГ`
(месяц без дня — годен до конца месяца).

## Иконка

Иконка приложения генерируется скриптом
`crates/apteka-tracker/assets/make_icon.py` (нужен Python с Pillow:
`pip install pillow`). Запуск из папки `crates/apteka-tracker`:
`python assets/make_icon.py` → `assets/icon.png` (иконка окна)
и `assets/icon.ico` (встраивается в exe при сборке через `winresource`).

## Структура проекта

Cargo workspace: ядро (`apteka-core`) отделено от интерфейса (`apteka-tracker`).

```
apteka-tracker/                 # корень = workspace
├── Cargo.toml                  # workspace: members = crates/*
├── crates/
│   ├── apteka-core/            # ядро без UI: переиспользуемо, полно тестируемо
│   │   ├── tests/perf_probe.rs # замер производительности на синтетике
│   │   └── src/
│   │       ├── lib.rs          # модули + реэкспорт chrono
│   │       ├── model.rs        # доменная модель, статусы, даты + тесты
│   │       ├── storage.rs      # JSON, бэкапы, фото + тесты
│   │       ├── csv.rs          # экспорт/импорт CSV + тесты
│   │       ├── input.rs        # валидация формы, календарь, фильтры + тесты
│   │       ├── state.rs        # DomainState: история, склейка правок + тесты
│   │       ├── settings.rs     # настройки окна/темы + тесты
│   │       └── history.rs      # undo/redo на снимках + тесты
│   └── apteka-tracker/         # приложение (exe)
│       ├── build.rs            # slint-build + иконка в ресурсы exe
│       ├── assets/             # icon.png/ico, make_icon.py
│       ├── ui/app.slint        # интерфейс (Slint)
│       └── src/
│           ├── main.rs         # точка входа, single-instance, main()
│           ├── state.rs        # UiState: домен + UI-состояние
│           ├── ui_sync.rs      # строки/списки UI из домена, статусы
│           ├── packages.rs     # форма упаковки, таблица упаковок, колбёки
│           ├── card.rs         # карточка лекарства: правки полей, фото
│           ├── windows.rs      # вторичные окна (журнал, отчёты, покупки…)
│           └── misc.rs         # persist, история отмены, настройки окна
└── docs/screenshot.png
```

## Тесты

```powershell
cargo test
```

Замер производительности на синтетической нагрузке (200/1000/5000 лекарств):

```powershell
cargo test --release -p apteka-core --test perf_probe -- --nocapture
```
